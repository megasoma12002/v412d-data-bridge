# DD_SWITCH 原母帳本固定的時鐘增益拆解

2026-10-09（台灣時間）。此研究延續使用者的原意：保留 L4 與 TRAIL42 的互補優勢，提高整體獲利；不把全套改成 T+1 當成原策略的替代答案。

## 能回答與不能回答的部分

已量出原研究對「當日選擇、當日取得所選帳本報酬」的敏感度。尚無法認證某個比例的收益可實盤執行：真實盤中 T+0 訊號、撮合價格、股份／現金及增量交易成本仍缺驗證。本次只做固定母帳本的報酬空間對照，不改參數、不重選 champion、不改 LIVE、不換成 #434 的 R1 控制來源。

## 為何與 Cursor 的 +3.5275 pp 不完全一致

原研究以完整 L4 母帳本作基準，2019+ 年化 16.3395%；DD_SWITCH 用兩母帳本共同日期的報酬串接，19.8670%，因此 +3.5274 pp，吻合原报告。

但 TRAIL42 沒有 2026-08-03～08-07 五個日期，及初始 2012-12-04。原程式 inner join 後把 L4 那五天的單日報酬丟掉，卻仍跟完整 L4 基準比較。

因此原標稱 +3.5274 pp 可作下列代數拆解（不是實現損益百分比分解）：

- 日期／對照報酬序列差異：+0.2516 pp。
- 把當日選擇延後一期後消失：+2.4822 pp。
- 原共同日期序列、延後一期仍保留：+0.7935 pp。

三項相加 = +3.5274 pp。母帳本缺日會影響日數年化、回撤觀測與可交易時鐘；本次沒有憑空填出 TRAIL42 缺日的每日報酬。

另做 calendar sensitivity：以母帳本 NAV 在共同觀測日之間的完整變化計算區間報酬，避免直接丟掉 L4 缺口日期的報酬，重新計算相同 DD 規則。2019+ L4 年化 16.3868%，same-day DD 19.8545%，lag1 DD 17.3842%；增益 +3.4677→+0.9974 pp，保留約 28.76%。這仍是區間資料模型，不能恢復缺口中每日可下單的決策，也不是開盤逐筆帳本。

## 成本敏感度

原共同序列有 343 次 lag1 選擇翻轉。增加「每次翻轉佔全帳戶 NAV 的 5／10／20／50 bp」作純敏感度，2019+ 年化依序為 15.6366%、13.9136%、10.5418%、0.9951%。

5 bp 已使其低於共同序列 L4，但此費率不是實測交易成本：實際要換多少股份、兩路徑持股重疊程度、交易稅与滑價皆未量出，不能把每次翻轉當成整個帳戶全部賣出重買。母帳本原有成本保留，這是额外切換費的假設。

## 判定與後續

目前「可執行互補優勢佔比」仍 INCONCLUSIVE。已有量化證據表明 same-day 時鐘假設對漂亮增益的影響很大，而且主要集中在 2023 之後；2019–2022 的延後一期增益反而保留約94%。不能用單一全年平均把所有優勢一筆抹去。

真正下一步是：補齐原母帳本日期及持股來源 → 保留原門檻 → 用盤中當時已知價格重算兩母帳本與 DD 訊號 → 在訊號之後撮合 → 只計成交後收益 → 加入現金回補、未成交訂單管理及實際成本。這樣才能評估盤中 T+0 能追回多少 2.4822 pp 的時鐘敏感差額，並區分「選擇優勢」與「切換執行」兩層。
