## 股利與公司行動

- 逐日保存開盤前持股作為除權息資格，先處理成交，再依記錄版本執行既有 E22 帳務。開盤買入不增加當日除權息權利，除息後出售不取消已認列的应收款。
- 應收股利在支付時移轉為現金；用唯一事件鍵防止重複入帳，沿用 TWSE 交易／交割日曆與 MOPS 支付修訂。股票股利以應享股數加回目前持股，不以買賣後全部持股重新計算。
- 庫內這段期間的部分發放日期來自 8/11、8/13 等較早的除權息事件，但這兩帳均自 8/24 空倉、8/25 起買入，沒有那些權利。**本視窗兩帳與各比較方案實際認列現金／股票股利均為 0**；不是省略股利來增加收益。
- 合成測試另外驗證有權利的現金應收、出售後支付、重跑去重、除息日才買入不得領取，以及股票股利只對除權前持股計算。這是機制驗證，不是本期間有領股利的證據。
- 公股／電信／0050 以 live_market 原始價格估值；民營金融用 raw_close，原始開盤價以 adjusted_open / backward_adjustment_factor 還原；00631L 用已有官方補齊快照。持倉價格缺漏會中止，不沿用昨日開盤價。股利涵蓋仍以庫中事件表為邊界，未另外宣稱對所有外部事件完成權威核對。

## 同一批五個政策的成交比較

反事實帳共同使用各參考來源截至當日收盤可知的訂單意圖與持股，投射尚未成交的訂單形成配置。只在實際有來源訂單時更新核心配置，沒有缺日核心訊號時維持先前意圖。帳戶風控每天觀察自己的 NAV；若風險比例變更，可以對已知配置產生新的管理訂單，不捏造核心策略訊號。

每組獨立現金／股數／股利帳，次交易日原始開盤加既有滑價成交，先賣後買，整張取整，手續費／證交稅、最低佣金及可用現金均生效。新目標取代舊目標，當日未成交餘量過期；沒有外部注資。

注意：參考帳保留原始成交，反事實 BASELINE 也會重新取整、限制總目標權重不超過 1、取消舊單，因此不是逐筆照抄參考成交。**政策效果應與同來源的 BASELINE 反事實帳比較**，不能把重規劃差異當成政策效果。

BASELINE 重規劃與原帳期末差 -25,745.48 元（-0.00515 個百分點）；R1 差 -10,725.83 元（-0.00215 個百分點）。這些差異是股數取整、現金及訂單生命週期的模型差異。

目前結果支持「多留現金減少回撤，也減少區間獲利」，沒有新增政策同時提高這兩項。32 個交易日不年化、不挑選長期冠軍，也不因此切換正式 live。
