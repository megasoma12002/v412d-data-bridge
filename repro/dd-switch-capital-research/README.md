# DD_SWITCH 自動化資金政策：固定候選、因果選擇

研究日期：2026-10-09（台灣時間）。**RESEARCH_PROXY_NO_LIVE_PROMOTION**。

## 結果先說

在五個事先定義的候選中，增加現金與帳戶回撤防守能降低觀察回撤，卻沒有提高淨年化。以「觀察 MDD 不超過 15%，在此限制下最大化 CAGR」選擇，2019–2026 每年僅用過去五年資料訓練都選回基準。沒有候選在 2019 年以後同時達到 CAGR 20% 和 MDD 不超過 15%。不應為了產生一個新策略而將勝出的基準排除。

以下為 **DD_SWITCH 固定母帳延後一期報酬代理** 的 2019 起至 2026-09-29 結果，不是目前整個 live 的歷史持股重播。成本假設：每次配置權重變動額額外扣 10bps；母帳原有成本已包含在來源中。

|原基準|16.30%|−14.41%|本輪 15% 回撤門檻下最高年化|

這裡的年化使用實際日曆時間與期間起始資本；此前時鐘歸因採每 252 個共同觀察值年化，數字不可直接比較。缺失母帳日期已在來源中聚合成區間報酬；區間內的每日決策、成交和回撤並沒有被恢復。

## 自動化規則與目標

`scripts/dd_switch_capital_policy.py` 是純研究控制器。輸入整個帳戶已知 NAV 與過去 20 個觀察值的趨勢；按帳戶高水位回撤控制下一期風險預算。退出不伴隨外部注資，也不因虧損而增加槓桿。

五個固定候選為 BASELINE、RESERVE_05、RESERVE_10、DD08_F60、DD08_F40。後兩者分別固定保留至少 5% / 10% 現金。降曝險即時生效；防守狀態保持到帳戶回撤回到 3% 以內且過去 20 期趨勢為正，再每個觀察日最多增加 5 個百分點。深度防守亦保持至此恢復條件，避免門檻附近頻繁反覆。

排名在程式中預先宣告：先選 MDD 不超過 15% 的候選，再最大化 CAGR；若全數不合格，選觀察 MDD 最小的候選。20% CAGR 是另行檢查的目標，不因沒有通過而擴大參數搜尋。另保留 0 / 10 / 30bps 權重變化成本敏感度。

2019 年前選擇及逐年訓練都不讀取之後資料。年度變更在同一自動帳戶持續的 NAV、峰值與防守狀態上執行，不拼接各候選的獨立 NAV。此為回顧性因果 walk-forward，使用已研究過的資料，不宣稱新的盲測樣本。

## 成交研究介面

盤中研究程式新增 `--capital-policy` 選项；例如：

```bash
python scripts/dd_switch_intraday_replay.py --bundle /path/to/verified_bundle --out /path/to/new_run --initial-cash 500000000 --capital-policy DD08_F60
```

控制器只讀取完整的前一交易日以前的研究帳 NAV，不用當日最終收盤淨值。以母帳完整配置乘風險預算後，交給既有現金／持股成交模型。買進預算另外扣除保留現金，避免手續費與滑價吃掉當次預算的現金底線。股數取整和無法成交的賣單仍可能使實際曝險高於目標，因此這是交易目標，不是最大回撤保證。

輸出事件紀錄含目標權重、風險比例、帳戶回撤、峰值與狀態，成本與成交紀錄共用一個帳戶。正式 live 設定、帳本與 workflow 未接此控制器；新方案還沒有真正盤中資料支持。
