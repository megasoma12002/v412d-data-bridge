# 危機保護與避免獲利誤傷：固定方案研究

**結論：目前沒有可升級live的穩定勝出方案。研究資金閉環已實作，但正式DD重新進場尚未修改。大盤惡化不等於金融／電信核心同步惡化；直接把大盤訊號轉成減碼或全退場，在本次後段會明顯誤傷。**

## 模型與預先固定方案

門檻未搜尋或事後調整，初始規格雜湊見 `summary.json`，規格檔在 `repro/dd-switch-crisis-profit-prespecified/policies.json`。

六個方案：核心無新增保護、原DD訊號加可回補資金帳、減半快速恢復、減半確認恢復、全退場確認恢復、原DD加減半。大盤警戒僅記錄、不交易：63個來源觀測日回撤達5%且5期跌3%；減碼條件：63期回撤達8%且20期跌3%，連續兩次確認。恢復條件：收盤高於MA20且5期報酬為正，快速方案1次、確認方案3次。半倉保留50%風險，全退場方案保留0%（股利零股另處理）。

這是**FIN/TEL核心袖套的配對實驗，不是完整live DD_SWITCH**：原母帳選擇與within-sleeve比例相同，5億元共同種子、95%初始核心配置、5%獨立現金保留；不含0050與民營金路徑，也沒有聲稱可取代全帳戶回測。

## 1. 回補資金閉環已在研究帳本成立

FIN、TEL各有獨立wallet，擁有可核對的初始資金、實際賣出淨額、實際股利／CIL現金與未花費資金。

- 每筆fill_id只入帳一次，買進扣gross+fees，賣出增加gross-fees；不能借用另一個wallet或5%保留款。
- 股利應收款列NAV但不可花費，股利實際入帳才增加可用現金；沿用E22_v3現金／股數／入帳與receivable帳本。
- 恢復ON時依「持股市值＋該袖套現金」規劃T+1整張目標；不重複發放原退出資金，資金不足買單保留正式整筆不成交政策。
- 資金橋接 `初始資金＋賣出淨額＋股利/CIL現金−買進實付＝期末cash` 在全部實驗通過；最大殘差7.28e-6元。
- 實例：原DD在2025/1/13 OFF、1/14 ON；研究帳本於1/15能回補金融／電信六筆買單，改善零市值planner鎖死的行為。這是研究wallet驗證，**尚未接入正式pipeline資金權限與狀態檔**。

研究wallet用分帳保護資金；production仍需完成實際DD退出事件標記、與0050/民營金現金權限整合、回補重試、遺留資金來源與關閉事件狀態。不能只把全帳戶cash加給planner。

## 2. 日期完整的44日窗口：減碼反而誤傷

來源日期完整窗口為2026/5/29–7/31，44個日曆交易日。窗口由資料覆蓋選定，不是按收益挑選；此期間所有新成交均為官方下一交易日，沒有延遲成交，股利／現金／股數與funding journal逐筆對帳。早期指標暖身仍來自有缺列的原歷史資料，因此不能將窗口成交驗證擴大成完整歷史或訊號認證。

| 核心配對方案 | 44日報酬 | 最大回撤 | 相對無新增保護NAV |
|---|---:|---:|---:|
| 核心無新增保護 | 21.6276% | -2.3656% | 基準 |
| 原DD＋研究回補帳 | 21.6276% | -2.3656% | 0 |
| 大盤訊號減半（快／確認恢復） | 16.9223% | -2.3656% | -23,526,448元 |
| 大盤訊號全退場 | 12.6890% | -2.3656% | -44,693,005元 |
| 原DD＋大盤訊號減半 | 16.9223% | -2.3656% | -23,526,448元 |

此核心帳本的主要回撤在7/2，新增大盤減碼從7/20收盤才開始、7/21開盤生效；沒有改善已發生的最大回撤，卻切掉後續核心上漲。減半方案在「基準下跌日」合計相對多賺163.90萬元，但在「基準上漲日」合計相對少賺2516.55萬元，合計少2352.64萬元。

上述逐日配對橋接含持股、費稅與資金路徑差異，是描述性分解，不能全稱為純誤報成本，也不能當作完整live策略或未來收益。

## 3. 長期診斷：2025有效、2026失效

2025發展段與2026時間切分段分別用相同5億元重新起算，另跑2025–2026連續帳本。2026日期在先前研究已被查看，**不是完全盲測樣本**。以下存在12個不完整交易日，只能作下一觀測日診斷，不能當精確T+1績效認證。

| 核心配對方案 | 2025報酬／最大回撤 | 2026截至10/8報酬／最大回撤 |
|---|---:|---:|
| 核心無新增保護 | 14.3837% / -10.0187% | 22.4776% / -8.3890% |
| 原DD＋研究回補帳 | 12.4348% / -10.0071% | 22.4776% / -8.3890% |
| 減半快速恢復 | 16.3778% / -6.2161% | 20.1100% / -9.0759% |
| 減半確認恢復 | 16.5685% / -6.2161% | 20.6338% / -9.3104% |
| 全退場確認恢復 | 18.1680% / -3.7309% | 18.5248% / -10.3068% |
| 原DD＋減半 | 14.5366% / -6.2073% | 20.6338% / -9.3104% |

不能只取2025全退場的漂亮結果就升級。連續期間減半確認方案略高於核心基準（40.7182% vs 40.4711%），但2026段少賺且回撤更大，尚無穩定跨段改善。

## 4. 新發現的歷史資料缺口

完整期間日曆428個交易日，只有416個同時具有市場與控制資料的日期：

- 市場面板缺7日：2025/2/6、6/11、6/12、6/13、6/16、6/17，以及2026/5/28。
- TRAIL母帳另缺5日：2026/8/3–8/7。BASE/L4與parent持股在該段有資料，不能把TRAIL的前值填入當作已完成估值。
- 市場建構器要求0050在共同面板；其停牌窗口會連同可交易的其他股票日期一起被篩掉。實際原因與原始金融raw/adjusted檔仍需補核；repo中缺原始artifact金融CSV，目前不能補造正確原始價格。

程式預設拒絕不完整日期；只有明確`--allow-observation-gaps`才產生診斷結果，沒有前值填價。延遲成交數逐方案公開，長期資料不得升級成精確T+1。`data_coverage_gaps.json`列出全部缺列。

## 5. 準確度與誤傷：不要只看單一命中率

另以「從T收盤起、未來20個完整交易日內最低收盤跌幅達10%」定義評估標籤，分別對TAIEX與無新增保護核心NAV計算precision/recall；未來資料只用於評估，不輸入控制器。最後20日以及缺價／缺NAV影響的完整視窗排除，不能當無危機標籤。

2026診斷的核心標籤沒有正事件，recall不可估；市場標籤則存在正事件。這說明以市場危機直接判定核心需減碼會誤判實際受損對象，不代表策略永遠免疫危機。完整TP/FP/FN/TN及分母見各結果目錄`label_precision_recall.csv`，不把有缺列的數字當正式命中率。

## 決策與下一階段

- 不升級任何新門檻或全退場方案。警戒可以先記錄；交易介入仍需驗證「核心／全帳戶實際風險是否同步惡化」。
- 優先補歷史市場與TRAIL估值缺列，重新確認完整成交／股利／公司事件帳本，再以相同固定方案重跑；保留現行原鏈資料作對照，不改寫凍結研究來源。
- 正式重新進場應整合已確認退出淨額與其他路徑現金占用；本次研究wallet證明方法可對帳，尚未完成production修復。
- 下一轮若加入核心／帳戶風險确认或早期加速度候選，應先凍結規則，重視誤報少賺、回補反彈損失與成本；不用這段輸贏搜尋最佳門檻。

## 程式與驗證

82項DD相關測試通過；新增wallet重複入帳、透支不跨袖套且失敗不改狀態、股利重複入帳、確認／恢復時鐘、DD優先權、完整未來標籤與因果指標測試。canonical forward歷史與runtime沒有改動；無合併、部署或券商交易。

`summary.json`为總結；`complete_window`為完整交易窗口輸出；`diagnostic`為明確有缺列的長期診斷。程式採現有E22與當前事件快照，尚非完整vintage PIT公司事件資料庫；固定5bp滑價不是市場深度證明，股利零股可能留下，現金收益設0。

```bash
PYTHONPATH=scripts python scripts/dd_switch_crisis_profit_research.py --out repro/NEW_COMPLETE_OUTPUT --epoch complete_window_2026_0529_0731
PYTHONPATH=scripts python scripts/dd_switch_crisis_profit_research.py --out repro/NEW_DIAGNOSTIC_OUTPUT --allow-observation-gaps
PYTHONPATH=scripts python -m unittest discover -s tests -p 'test_dd_switch*.py'
```

使用新的輸出目錄；工具拒絕覆寫既有研究。逐模型完整nav、成交、持股、funding journal與order attempts皆可由程式重建；提交的證據保留全部模型摘要／nav，以及連續段与完整窗口的完整交易資金證據。
