# DD_SWITCH 危機訊號、退場與重新進場稽核

結論：優先補「退場後重新進場的資金閉環」，再研究危機訊號；目前不能把 DD_SWITCH 視為全帳戶危機開關。現行門檻與交易規則已凍結，僅新增研究程式／測試，未合併或部署。

## 核對範圍

使用已核對的 original-lineage 八項來源，2012/12/5–2026/10/8 共 3,367 個共同控制觀察日。保留原研究影子 NAV 的歷史拼接、估值與公司事件假設；這是控制訊號歷史稽核，不是重新認證整段 exact T+1 live 績效。

- 原始規則不變：TRAIL 的 DD 優於／等於 L4 時選 TRAIL；只有在 TRAIL 被選中且前一日以前的42期 P3 超額報酬和小於 -1% 時，核心 FIN/TEL OFF。選 L4 的日子核心仍 ON。
- 全期間 10 次 OFF、10 次恢复 ON，共58個 OFF 觀察日。每個切換點做截斷來源重算，20項前綴測試與完整來源結果一致；premium 已 shift(1)，未再增加訊號延遲。
- 目前只具2025/2026官方交易日檔：20個歷史退出／恢復時鐘中，4個可正式核對下一交易日；其餘16個明確標為下一個市場資料觀察日，不能冒稱官方成交時鐘已全期間認證。

## 1. 退場能成交，恢復 ON 卻不會自動回補

對10組歷史 OFF→ON 各建立一個**合成**5億元、95%核心FIN/TEL、5%現金的整張母帳形狀持股，調用現行 DD apply 與 paper fill core；不是當年的真實券商持股。

所有條件探針都能在下一市場觀察日賣出核心持股，無同日成交。對應 ON 日的母帳都有正核心持股，但現行 `plan_delta_ledger_scaled` 在平倉後的 FIN/TEL 市值均為0，因而10個條件探針全數產生0筆回補買單。

因果鏈：**完整退場 → 核心持股市值歸零 → planner用當前持股市值當資金預算 → ON時目標仍為零**。帳戶有現金不能自動解決，因為planner沒有讀取 DD 退出資金或全帳戶現金預算。

### 完整 pipeline 狀態驗證

另外用已核對9/29真實paper種子，隔離注入9/30與10/1 OFF、10/2起 ON，完整重跑正式pipeline七個日期：

- 10/1七筆核心賣單全部成交；當日起核心持股為0。
- 10/2、10/5、10/6、10/7、10/8皆ON，核心回補買單仍0筆。
- 現金／股數／NAV對帳通過；最大NAV殘差2.39e-7元、期末股數殘差0、QC PASS。
- 此人工訊號注入只證明交接程式行為，不能宣稱是 DD 原訊號或策略報酬。

舊未成交核心買單能明確取消、不在下一日復活，相關探針與測試通過。問題主要是重新進場資金來源沒有接到現行planner。

## 2. OFF 範圍僅七檔核心，不是全帳戶股票

核心四檔金融為2880/2886/2892/5880，電信為2412/3045/4904。

0050與民營金2881/2882/2884/2885/2890/2891不在這個flatten集合。人工OFF測試中，OFF訊號日期仍有7筆核心以外的BUY意圖（0050及六檔民營金），並在後續開盤成交。這符合目前程式作用範圍，不能把「FIN/TEL→cash」解讀成整個帳戶退出風險。

其他層可能另有自己的風險規則；本稽核沒有否定那些規則，也沒有將所有路徑強制關閉。

## 3. 相對績效開關不能代替大盤危機偵測

為避免挑日期，對TAIEX收盤以持續創高後的peak→trough→recover區段，列出**全部**最大回撤達10%的9段事件。10%僅用於事件分類，不是新策略參數。

| 大盤區段 | 大盤回撤 | 跌至谷底期間的 DD 核心 OFF 日數 |
|---|---:|---:|
| 2014/7–2014/10 | -11.04% | 0 |
| 2015/4–2015/8 | -25.70% | 0 |
| 2018/1–2019/1 | -16.62% | 0 |
| 2020/1–2020/3 | -28.72% | 0 |
| 2021/4–2021/5 | -12.74% | 0 |
| 2022/1–2022/10 | -31.63% | 19 |
| 2024/7–2025/4 | -28.69% | 1 |
| 2026/2–2026/3 | -10.42% | 0 |
| 2026/6–2026/7 | -16.36% | 0 |

**這些是大盤回撤，不是DD_SWITCH組合回撤。** 7段下跌期間完全沒有核心OFF；2022第一次OFF在9/28，當時大盤距該峰值已跌27.31%。2024/7–2025/4那段只在2025/1/13 OFF一日，隔日已重新ON，不能據此宣稱涵蓋後續下跌。

原因是DD比較的是兩個策略的相對回撤與P3超額報酬；即使大盤劇跌，L4仍可能被選中而保持ON。危機研究應評估獨立、全帳戶的風險層，不能直接用這個相對策略切換器替代。

## 下一步優先順序

1. 實作並隔離驗證 DD 退出資金的重新進場契約：按FIN/TEL記錄實際賣出淨額、現金占用與回補，避免借用0050或民營金資金；具體設計見 `reentry_funding_contract.md`。尚未改動production。
2. 補足歷史官方交易日與完整事件帳本，再做退出／再進場的全期間精確成交重播；不能用這次訊號掃描直接宣稱最大回撤或年化。
3. 前兩項完成後，再固定候選的全帳戶危機層，延續 E38–E45 的及時性研究，評估回撤降低、錯誤退場、回補少賺與交易成本。先不重調DD的42期/-1%門檻。
