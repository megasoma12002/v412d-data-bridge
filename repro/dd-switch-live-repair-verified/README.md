# DD_SWITCH 同日來源與初次接手修復

狀態：程式已實作、紙上成交重播通過；PR434 尚未合併或部署，未執行券商交易。

## 修復內容

1. 同日來源：每日以已核對的原 DD_SWITCH 建構鏈更新八項來源，同一 asof、雜湊與歷史前綴檢查全部通過才原子切換 runtime。凍結截至 9/29 的原始研究輸入；價格下載只補新日期。資料缺漏、版本錯誤或母帳過期均阻擋接手，不能先抑制舊策略卻沒有替代委託。
2. 初次接手：先處理先前委託的開盤成交，再依實際持股及原有 sleeve 資金尺度計算差額；同日收盤訊號產生下一交易日開盤委託。記錄接手持股、現金、來源與委託 ID，後續追蹤成交／替代狀態。
3. 成交餘量：保留歷史成交，明確取消三筆失去追蹤的舊部分成交餘量共 23,000 股。依當前目標重算，不直接重買九月舊目標。現有買單資金不足仍採整筆等待；最新目標替代未成交意圖時留下取消事件，避免新舊雙重掛單。
4. 漏跑日期：單日入口拒絕跳過官方交易日；範圍入口依序處理最後已提交日期之後的所有新交易日，先驗證完整價格。重試已提交日期不新增成交。歷史補跑明確標為 PAPER_HISTORICAL_CATCHUP，不宣稱是即時或券商成交。

## 上線界線與仍保留的限制

合併後下一次接手應從當時實際已提交持股／現金開始，不把研究重播成交塞回既有 live 歷史。早於最後已提交日期的漏跑交易不補造，僅可另外做估值與對照。資料發布和工作流程已改碼，但尚未在 main 上執行。

本驗證為紙上固定開盤滑價與費率重播，非券商成交或流動性證明。保留原研究影子 NAV 的拼接與歷史公司事件假設作為收盤控制特徵；P3 訊號仍是 T 收盤到 T+1 開盤。資金不足買單政策、策略門檻與退場後再進場的 sleeve 資金規則沒有在本次另行優化。
